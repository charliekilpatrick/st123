Welcome to st123’s documentation!

st123 is a Python toolkit for space-telescope imaging: query and download from MAST, align with a repository-local build of JHAT, build mosaics / coadds, prepare DOLPHOT runs, and scrape photometry catalogs. Designed for HST, JWST, and Roman, with current workflows strongest for JWST (and HST reference / MAST helpers).

  • Installation — Python 3.11–3.12, Conda, optional DOLPHOT / JWST.

  • User guide — Work-directory layout, CLI overview, outputs.

  • API — package modules (MAST, alignment, mosaic, photometry, utils).

Quick install

From the repository root (see Installation for detail):

conda create -n st123 python=3.12 pip
conda activate st123
pip install -e .

Build this documentation locally:

pip install -e ".[docs]"
cd docs && make html

The documentation workflow publishes to GitHub Pages.

Repository layout

  • st123/ — installable package: scripts/ (CLIs), mast/, alignment/, mosaic/, photometry/, utils/, notebooks/.

  • extdeps/jhat/ — custom JHAT tree used by editable installs.

  • tests/ — pytest suite.

  • docs/ — Sphinx (reStructuredText + MyST Markdown): this site and changelog.
